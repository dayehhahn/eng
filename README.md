# 학업중단, 생각과 실제는 어디까지 겹칠까? (2026 데이터분석 연구발표회)

- 웹앱 링크: (배포 후 여기에 붙여넣기)
- 자료: 2025 「학업중단 생각 여부 및 이유」, 2023 「학업 중단 사유」 (KOSIS 통계표, 출처·URL은 연구 보고서에 표기)

## 파일
| 파일 | 설명 |
|---|---|
| app.py | Streamlit 웹앱 |
| charts.py | 계산·그래프 함수 (app.py가 불러 씀) |
| long.csv | 두 자료를 긴 형태로 합친 가공 데이터 (UTF-8) |
| mapping.csv | 2023 사유 ↔ 2025 이유 대응표 (엄격/기본/완화) |
| requirements.txt | 필요한 파이썬 패키지 |

## 로컬 실행
    pip install -r requirements.txt
    streamlit run app.py

## 데이터 처리 요약
- 원본 CSV의 머리글(2023: 4줄, 2025: 3줄)을 한 열 이름으로 결합하여 긴 형태로 변환
- '-'는 0이 아닌 결측으로 처리, 항목명 앞뒤 공백 제거
- 1순위·'있다/없다' 합계가 100±1.0 이내인지, 2023 누적 순위(1순위 ≤ 1+2순위 ≤ 1+2+3순위) 관계가 맞는지 검증

## 해석상 주의
- 2023과 2025는 조사 연도·대상·선택지가 달라 '증감'이 아니라 대응 항목의 순위·비중 방향만 비교
- 집단 차이는 상관이며 인과가 아님, 표본 크기·오차는 원자료에 없어 '유의하다'는 표현을 쓰지 않음

## 생성형 AI 활용
Claude를 코드 초안 작성(CSV 읽기, 머리글 결합, 그래프, 웹앱)과 오류 원인 확인에 사용하였다.
연구 질문, 대응 항목 판정, 해석과 제안은 팀이 직접 결정하였고, 계산 결과는 원본 통계표 값과 직접 대조하였다.
